internal data class GalleryBackupRecord(val createdAt: Long = 0, val generationType: String = "txt2img", val prompt: String = "", val negativePrompt: String = "", val width: Int = 512, val height: Int = 512, val samplingSteps: Int = 20, val cfgScale: Float = 7.0f, val isRestoreFaces: Boolean = false, val sampler: String = "", val seed: String = "", val subSeed: String = "", val subSeedStrength: Float = 0.0f, val denoisingStrength: Float = 0.0f, val isHidden: Boolean = false, val isLiked: Boolean = false, val modelName: String = "", val providerKey: String? = null, val acceleration: String? = null, val deviceName: String? = null, val osVersion: String? = null, val generationDurationMillis: Long? = null, val civitaiUrl: String? = null)(source)

Portable image metadata. Images are separate binary frames; local IDs, revisions and transient guards are never serialized.

Dmitriy Moroz

Parameters

createdAt

Original creation time in epoch milliseconds.

generationType

Stable txt2img/img2img discriminator; future values are skipped.

prompt

Original positive generation prompt.

negativePrompt

Original negative generation prompt.

width

Positive output width in pixels.

height

Positive output height in pixels.

samplingSteps

Recorded sampling steps, including zero for providers that do not expose a sampler.

cfgScale

Finite guidance scale recorded by generation.

isRestoreFaces

Whether face restoration was requested.

sampler

Recorded sampler identifier; an empty value is preserved.

seed

Original textual seed without numeric reinterpretation.

subSeed

Original textual variation seed.

subSeedStrength

Finite variation strength recorded by generation.

denoisingStrength

Finite image-to-image denoising strength.

isHidden

Whether the history item is hidden from the gallery.

isLiked

Whether the history item is marked as a favorite.

modelName

Original generation model name without requiring that model on the destination.

providerKey

Captured provider catalog key; null for images created before provenance was recorded.

acceleration

Execution mode used for this image; null when unknown, "None" for remote providers.

deviceName

Originating device vendor and model, retained across transfers; null for legacy images.

osVersion

Originating OS version, including Android API level; null for legacy images.

generationDurationMillis

Elapsed generation milliseconds, including provider setup and queueing, excluding gallery/export writes; null for legacy images.

civitaiUrl

Confirmed public Civitai post URL; null for older archives or unpublished images.
