TextToImageTask

internal class TextToImageTask(context: Context, workerParameters: WorkerParameters, pushNotificationManager: PushNotificationManager, activityIntentProvider: ActivityIntentProvider, observeHordeProcessStatusUseCase: ObserveHordeProcessStatusUseCase, remoteGenerationProgressGateway: RemoteGenerationProgressGateway, observeEasyDiffusionProgressUseCase: ObserveEasyDiffusionProgressUseCase, interruptWorkerGenerationUseCase: InterruptWorkerGenerationUseCase, val preferenceManager: PreferenceManager, val backgroundWorkObserver: BackgroundWorkObserver, val textToImageUseCase: TextToImageUseCase, val payloads: GenerationWorkPayloadStore, val payloadCleanup: GenerationWorkPayloadCleanup, nativeGateway: NativeGenerationGateway) : CoreGenerationWorker(source)

Background txt2img worker.

The task reads the cached generation payload, starts provider-specific progress observation, executes txt2img generation, and reports success, cancellation, or failure through the foreground notification path. Native attempts, including Bonsai, are never automatically replayed after interruption.
