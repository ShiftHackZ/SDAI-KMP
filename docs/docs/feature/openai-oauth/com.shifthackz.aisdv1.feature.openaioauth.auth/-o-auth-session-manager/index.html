OAuthSessionManager

class OAuthSessionManager(val auth: OAuthApi, val images: ImageApi, val store: SessionStore)(source)

Owns device login, protected credentials and refresh rotation independently from application models. Login/logout change the identity revision; token refresh does not. Credential-bearing exceptions and HTTP bodies are discarded before crossing the public boundary.
