KtorCivitaiApi

internal class KtorCivitaiApi(val client: HttpClient, val clientId: String, val redirectUri: String) : CivitaiApi(source)

Implements Civitai's official presign → object PUT → atomic post.createWithImages protocol. The isolated client has no logger, auth defaults, redirects or retry plugin.
