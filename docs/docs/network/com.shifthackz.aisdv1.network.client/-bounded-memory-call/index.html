BoundedMemoryCall

internal class BoundedMemoryCall(client: HttpClient, origin: HttpResponse, bytes: ByteArray) : HttpClientCall(source)

Holds only an already bounded response and preserves normal Ktor typed decoding/error access. Uses the same detached-body/context convention as Ktor 3.5 SavedHttpCall: response cleanup completes the network job; later body decoding reads only a fresh in-memory channel.
