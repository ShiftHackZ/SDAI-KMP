AiGenerationResult

data class AiGenerationResult(val id: Long, val image: String, val inputImage: String, val createdAt: Long, val type: AiGenerationResult.Type, val prompt: String, val negativePrompt: String, val width: Int, val height: Int, val samplingSteps: Int, val cfgScale: Float, val restoreFaces: Boolean, val sampler: String, val seed: String, val subSeed: String, val subSeedStrength: Float, val denoisingStrength: Float, val hidden: Boolean, val liked: Boolean = false, val modelName: String = "", val openAiOAuthIdentity: OpenAiOAuthIdentity? = null, val providerSelectionRevision: Long? = null, val imageRevision: String = "", val providerKey: String? = null, val acceleration: String? = null, val deviceName: String? = null, val osVersion: String? = null, val generationDurationMillis: Long? = null, val civitaiUrl: String? = null)(source)

Generated image, metadata and transient guards used by gallery persistence.

Author

Dmitriy Moroz

Parameters

id

Persistent gallery identity, or zero before insertion.

image

Original encoded output image as Base64.

inputImage

Optional encoded source image as Base64, empty for text generation.

createdAt

Creation timestamp in epoch milliseconds.

type

Text-to-image or image-to-image operation.

prompt

Positive generation prompt.

negativePrompt

Negative generation prompt.

width

Output width in pixels.

height

Output height in pixels.

samplingSteps

Requested sampling iteration count.

cfgScale

Classifier-free guidance scale.

restoreFaces

Whether face restoration was requested.

sampler

Sampling algorithm identifier.

seed

Resolved provider seed text.

subSeed

Variation seed text.

subSeedStrength

Variation seed influence.

denoisingStrength

Image-to-image denoising influence.

hidden

Whether the output is obscured in the gallery.

liked

Whether the output is a favorite.

modelName

Recorded model name, independent of currently selected model.

openAiOAuthIdentity

Original OAuth account/revision for an unsaved result; not persisted in gallery rows.

providerSelectionRevision

Source-selection revision captured during OAuth generation; null for other providers.

imageRevision

Content identity used to invalidate cached gallery previews.

providerKey

Captured provider catalog key; null for images created before provenance was recorded.

acceleration

Execution mode used for this image; null when unknown, "None" for remote providers.

deviceName

Originating device vendor and model, retained across transfers; null for legacy images.

osVersion

Originating OS version, including Android API level; null for legacy images.

generationDurationMillis

Elapsed generation milliseconds, including provider setup and queueing, excluding gallery/export writes; null for legacy images.

civitaiUrl

Public Civitai post URL after publication, absent for unpublished images.
