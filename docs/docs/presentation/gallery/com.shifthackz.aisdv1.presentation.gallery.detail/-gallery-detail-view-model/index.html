GalleryDetailViewModel

class GalleryDetailViewModel(diagnostics: UiDiagnostics, val itemId: Long, val dispatchersProvider: DispatchersProvider, val buildInfoProvider: BuildInfoProvider, val getGenerationResultUseCase: GetGenerationResultUseCase, val getAllGalleryIdsUseCase: GetAllGalleryIdsUseCase, val getLastResultFromCacheUseCase: GetLastResultFromCacheUseCase, val deleteGalleryItemUseCase: DeleteGalleryItemUseCase, val toggleImageVisibilityUseCase: ToggleImageVisibilityUseCase, val toggleImageLikeUseCase: ToggleImageLikeUseCase, val generationFormUpdateEvent: GenerationFormUpdateEvent, val router: GalleryDetailRouter, val platformActions: GalleryDetailPlatformActions, val galleryReads: GalleryReadGateway, val contentCache: GalleryDetailContentCache, val pagerBuffer: Int = GALLERY_DETAIL_PAGER_BUFFER, val onError: (Throwable) -> Unit = {}) : BaseMviViewModel<GalleryDetailState, GalleryDetailIntent, EmptyEffect> (source)

Maintains detail navigation with bounded metadata prefetch and revision-fenced asynchronous reads. Original bytes are loaded for explicit save/share/form-restoration actions, preserving page/cache identity.

Author

Dmitriy Moroz

Parameters

diagnostics

Optional bounded observer for detail MVI transitions.

itemId

Initial persistent identity, or nonpositive to open the last cached result.

dispatchersProvider

Separates storage/native work from immediate UI publication.

buildInfoProvider

Controls distribution-specific report visibility.

getGenerationResultUseCase

Loads complete original content for explicit image actions or form restoration.

getAllGalleryIdsUseCase

Reads gallery ordering without retaining original images.

getLastResultFromCacheUseCase

Loads a transient generation when no persistent identity exists.

deleteGalleryItemUseCase

Deletes the confirmed current persistent generation.

toggleImageVisibilityUseCase

Changes the current generation's hidden state.

toggleImageLikeUseCase

Changes the current generation's favorite state.

generationFormUpdateEvent

Transfers captured parameters/source choice to a retained generation form.

router

Handles detail dismissal, report navigation and form destinations.

platformActions

Performs native original-image export, sharing and clipboard operations.

galleryReads

Reads and observes current/neighbor metadata revisions.

contentCache

Stores only the currently retained detail metadata window.

pagerBuffer

Neighbor count requested on either side, clamped to zero or one.

onError

Receives read, navigation, mutation and native-action failures.
