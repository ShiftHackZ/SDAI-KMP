TextToImageIntent

sealed interface TextToImageIntent : MviIntent(source)

User actions and form updates emitted by the txt2img screen.

Benchmark warning actions are modeled here with regular generation intents so the view-model can gate local providers without coupling the shared input form to benchmark-specific UI.
