Render state for the retained image-to-image form and its inpaint editor. Implements the shared generation-control contract without making every provider or control applicable to img2img. mapToPayload selects request fields; shared-form compatibility values such as OpenAI options, local backend selectors and hires do not enable unsupported sources.

internal fun ImageToImageState.mapToPayload(maskBase64: String? = null): ImageToImagePayload

Captures the source/revision, image and normalized form values in an image-to-image request. Trims prompt and seed text, uses Fal.ai preset dimensions or numeric dimensions with a 512-pixel fallback, and restricts scheduler, safety and extension options to their applicable sources. The mapper does not validate the request or encode mask strokes.
