MNN SD 1.5

Alpha local text-to-image generation on Android arm64 with MNN 3.6.2. Each request creates one 512×512 image using PNDM, fixed CFG 7.5 and 1–50 sampling steps. Select CPU or OpenCL in the generation form. An unavailable OpenCL backend fails explicitly; selecting OpenCL does not guarantee that every operation runs on the GPU.

Models and setup

Choose MNN in provider setup, download a model when one is available in the catalog, select it and connect. A complete validated bundle can be reused offline. The initial catalog has no distributed bundles yet.

Full and FOSS builds also support the existing custom model folder picker. Extract a complete compatible bundle into a folder accessible to the application, enable the custom model option, choose the folder and connect. Keep all root files, including manifest.json, tokenizer.mtok and the three .mnn.weight sidecars. Setup checks the complete bundle and creates a private immutable copy for generation; deleting that copy through app storage leaves the original folder untouched.

Allow several GB of free storage for the approximately 1.15 GB model, staging and the private custom copy. Model loading and generation require substantial memory; compatibility and performance depend on the device and its drivers.

Supported controls

Positive prompt, sampling steps, seed and CPU/OpenCL selection are supported. Negative prompts, image-to-image, batches, LoRA, arbitrary checkpoints, fused graphs and NPU execution are unavailable. iOS does not expose the MNN provider.

Maintainers

Packaging guide: reuse the pinned general prebuilt weights, export the matching tokenizer, verify graph declarations and package a manifest with checksums and the model license. End users do not need conversion tools.
