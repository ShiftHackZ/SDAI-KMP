## SDAI Nightly Builds are live

From now on, we will publish fresh Android preview builds with the newest SDAI changes.

If you are not a developer: think of a nightly build as an early-access version of SDAI. It is the place to try new fixes and features before they arrive in a regular release.

Use nightly builds when:
- you want to try the newest SDAI changes early
- you are okay with small bugs or unfinished edges
- you want to help us catch problems on real devices

Stick with the stable build when you just need SDAI to be predictable.

Get the latest nightly build here:
<https://sdai.moroz.cc/nightly.html>

If you try it, please share what phone you used and what worked well or felt broken. That feedback helps us make the regular releases better.
