SDAI now has an Android nightly channel for people who want to try fixes and features before the next stable release. If you've reported a bug and a fix has landed in development, a nightly is a way to try it on the same phone and provider where you first saw it.

## Install the preview

The [SDAI Nightly Build page](/nightly.html) always links to the latest published Android APK. The daily workflow builds the Full edition from the development branch and can skip days when only documentation or other non-app files have changed. The date and commit in the version help identify which build you're running.

The current nightly installs as SDAI Dev, with a DEV badge on its launcher icon. You can keep it alongside your stable SDAI installation. Settings, provider credentials, and generation history are separate, so expect to set up your provider again the first time you open SDAI Dev.

## Try the change that brought you here

Start with a workflow you know. If a fix was supposed to help when connecting to a server, try the same provider and setup again. If it changed gallery behavior, open an existing result and repeat the save or share action you were using. A short report is enough when it says what you did, what you expected, and what happened instead.

Include your phone model, Android version, and nightly build version when you file a report. Mention the selected provider if the issue involves setup or generation. Keep the [stable build](/#get-app) handy for everyday generation while you're testing a preview.
