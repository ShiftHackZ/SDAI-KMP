## SDAI 1.1.0 is live

SDAI 1.1.0 is one of our biggest feature releases so far. The goal is simple: give you more ways to generate images, more confidence before running local models, and better visibility into what the app is doing on your device.

### Highlights

- **On-device benchmark** - check whether your device is a good fit for local generation before starting a heavy run.
- **More local generation** - Android now has Local SDXL through stable-diffusion.cpp, and iPhone has Core ML plus PrismML Bonsai on supported devices.
- **New providers** - Fal.ai and ArliAI are now part of the provider lineup.
- **Cleaner provider selection** - search, filters, readiness labels, and feature tags make the setup flow easier to navigate.
- **Storage and network usage** - see model files, cache, gallery usage, and provider traffic from Settings.
- **iOS improvements** - better gallery loading and background-work handling.

SDAI remains open source, ad-free, telemetry-free, and provider-first.
