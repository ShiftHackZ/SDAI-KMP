SDAI 1.1.0 is live.

This release is a big step toward making SDAI feel like a real mobile AI workspace, not just a place where you pick a backend and hope it works.

What's new:

- (Beta) Benchmarks before local generation. SDAI can check your device and suggest realistic local settings before you start a heavy run.
- (Beta/Alpha) More local AI options. Android gets Local SDXL through stable-diffusion.cpp, while iPhone gets Core ML and PrismML Bonsai on supported devices.
- More provider choice. Fal.ai and ArliAI join the provider list, alongside the existing self-hosted and cloud options.
- Better provider selection. Search, filters, readiness badges, and tags make it easier to pick the right backend.
- Storage and network usage. See what models, cache, gallery items, and provider traffic are using.
- Smoother iOS work. Gallery loading and background tasks got attention too.
