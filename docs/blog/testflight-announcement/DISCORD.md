## SDAI TestFlight Beta is now public

We have opened a public TestFlight invite for iOS.

TestFlight is Apple's beta testing app. It lets iPhone users try upcoming SDAI builds before those changes reach the regular App Store version.

Use it if you want to:
- try recent fixes and UI updates early
- help validate new app behavior on real iPhones
- send feedback before a stable release goes out

A small beta warning: TestFlight builds move faster than the App Store version. They can include unfinished or changing behavior, so the App Store build is still the better choice for everyday use.

Thanks for helping us make SDAI releases better before they ship.
