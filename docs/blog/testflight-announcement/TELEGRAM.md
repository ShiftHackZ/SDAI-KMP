SDAI TestFlight Beta is now public.

We have opened a public TestFlight invite for iOS.

If you use SDAI on iPhone and want to try upcoming changes before they reach the regular App Store version, this is now the easiest way to do it: open the beta page, join TestFlight, install the build, and send feedback when something feels off.

Quick note: TestFlight builds are beta builds. They may include new fixes, UI updates, and app behavior we are still validating. If you want the calm everyday version, stay on the App Store. If you like being early and helping shape releases, TestFlight is for you.
