**SDAI 1.3.0 is live on the App Store and Google Play.**

- Run Stable Diffusion 1.5 offline with **MNN** on supported phones.
- Connect to **Easy Diffusion**, an **OpenAI-compatible server**, or **ChatGPT via OAuth**.
- Choose what to include in a **backup**, from provider settings to gallery and history.
- **Publish to Civitai** from your gallery and reopen the post from image details.
- See elapsed time, **generation progress** where available, and live CPU and RAM usage.

Read the release notes for model requirements, provider setup, and store links.
