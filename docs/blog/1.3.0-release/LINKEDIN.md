SDAI 1.3.0 is out on the App Store and Google Play. You can now run Stable Diffusion 1.5 offline with MNN on supported Android phones and iPhones. If you generate remotely, the update adds Easy Diffusion, OpenAI-compatible servers, and ChatGPT OAuth.

Selective backups let you keep the settings and images you want to restore later. You can also publish to Civitai directly from the gallery. SDAI keeps the post link with the image so you can find it again.

Read the release notes for provider setup, Android and iPhone requirements, and what the update changes during generation.
