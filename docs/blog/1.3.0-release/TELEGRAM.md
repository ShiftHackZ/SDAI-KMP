**SDAI 1.3.0 is out for Android and iPhone.**

Run Stable Diffusion 1.5 offline with **MNN** on supported phones, or connect to **Easy Diffusion**, an **OpenAI-compatible server**, or **ChatGPT via OAuth**.

You can also publish images to **Civitai** from the gallery, pick what goes into a backup, and check elapsed time and live CPU and RAM usage during generation.
