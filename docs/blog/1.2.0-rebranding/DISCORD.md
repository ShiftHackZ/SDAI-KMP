## SDAI 1.2.0: a new look

We're simplifying the name to **SDAI** and introducing a new icon: a colorful frame around a small landscape. It gives our independent AI image generation app an identity of its own.

The 1.2.0 update includes:

- **New branding** across the app, website and store artwork.
- **German language support** on Android and iOS.
- **FOSS and FULL launcher labels** to distinguish the Android variants.
- Updated app copy, repository links and API documentation.

SDAI remains open source, with support for self-hosted servers, hosted providers and on-device generation on supported devices.

The source repository is now **ShiftHackZ/SDAI-KMP**.
