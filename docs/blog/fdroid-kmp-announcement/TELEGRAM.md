SDAI 1.1.1 is now available on F-Droid.

This is the first release from SDAI's new Kotlin Multiplatform line to reach F-Droid — the shared foundation behind the modern SDAI experience on Android and iPhone.

If your F-Droid install was still on 0.6.8, this is the long-awaited jump to the new generation of the app.

What to know:

- Version 1.1.1 (208) is now the suggested F-Droid release.
- This FOSS build is arm64-v8a only.
- Android 7.0 or newer is required.
- SDAI remains open source, ad-free, telemetry-free, and provider-first.

Install or update through F-Droid:
