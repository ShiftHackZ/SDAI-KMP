SDAI has passed App Store review and is available for iPhone. Once you've installed it, you can connect a provider you already use or try a model on your phone. [Download SDAI on the App Store](https://apps.apple.com/us/app/sdai-ai-image-generator/id6778314183).

## Set up your first generation

If you already have a Stable Diffusion server, open SDAI's Configuration screen and choose the provider that matches your setup. Enter the server address your iPhone can reach. For a server on your home network, that usually means using its local network address while the phone is on the same network.

You can also connect a hosted provider you already use, or pick an on-device option if your iPhone and model are compatible. The controls depend on the provider. Some offer extra settings such as samplers or a negative prompt, while others ask for little more than a prompt and an image size. See the [SDAI setup FAQ](/faq.html) if you're deciding where to start.

## From a prompt to the gallery

Start with a text prompt and generate an image. You can review the result in SDAI's local gallery, then save or share the ones you want to keep elsewhere. Where the image is generated depends on the provider you chose. A remote provider receives what it needs to process your request, while an on-device provider can run locally once its model is available. See [how SDAI handles provider data](/privacy.html).
