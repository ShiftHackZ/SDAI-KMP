## SDAI is now on the App Store

We made it. SDAI has passed App Store review and is officially live for iPhone.

For users, this means the simplest possible install path on iOS: open the App Store, install SDAI, and start using it with the AI provider that fits your workflow.

What stays the same:
- no ads
- no telemetry
- open source
- provider-first workflows
- a clean local gallery for your results
