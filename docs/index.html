SDAI connects to popular AI providers including AUTOMATIC1111, SwarmUI, OpenAI-compatible image servers, AI Horde, Hugging Face Inference, OpenAI, ChatGPT OAuth, Stability AI, Fal.ai, ArliAI, and Local Diffusion engines.

Local generation spans Android ONNX, Google AI MediaPipe, stable-diffusion.cpp SDXL, iOS Silicon Diffusion Core ML, and PrismML Bonsai Image 4B on supported devices.

Keep the controls artists expect: positive and negative prompts, size, seed, CFG scale, sampling steps, restore faces, Img2Img, Inpaint, LoRA, embeddings, hypernetworks, and model selection where supported.

Provider coverage

One app for self-hosted, hosted, and on-device generation.

Cloud and self-hosted

Use AUTOMATIC1111, SwarmUI, Easy Diffusion, OpenAI-compatible, ChatGPT OAuth, AI Horde, Hugging Face, OpenAI, Stability AI, Fal.ai, or ArliAI from the shared generation flow.

ChatGPT OAuth · Beta

Sign in with ChatGPT and generate directly with gpt-image-2 on Android and iOS. Device-code login, protected local sessions and sequential batches. Account access and service limits apply.

Sign-in and provider guide

Easy Diffusion · Stable

Connect an Easy Diffusion v3 server by LAN URL on Android or iOS. SD1.5 txt2img and img2img, checkpoint selection, fixed DDIM, progress, task cancellation and sequential batches. Enable network sharing, save and restart the server before connecting.

OpenAI-compatible · Stable

Connect your image server or proxy with a full API URL and an optional key. Enter its model ID and generate with txt2img and sequential batches on Android or iOS.

Setup and troubleshooting

Local engines

Run Android ONNX, MediaPipe, stable-diffusion.cpp SDXL, iOS Core ML, or PrismML Bonsai after choosing a compatible model. MNN SD 1.5 is also available in alpha on both platforms.

Device fit and usage

Use benchmark recommendations for local providers, then review storage and network counters from Settings.
